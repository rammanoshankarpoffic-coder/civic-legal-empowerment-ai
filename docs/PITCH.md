# Pitch Script — Nyaya Sathi (3-minute demo)

## Hook (20s)
"Every year, millions of Indians are entitled to something — an RTI answer, a security
deposit, a scholarship, a scheme benefit — and never get it. Not because the right
doesn't exist, but because the *process* to claim it is scattered across PDFs, portals,
and jargon nobody has time to decode."

## Problem (20s)
- RTI applications: intimidating format, wrong department, application gets rejected.
- Tenant/consumer disputes: people don't know what they're even entitled to.
- Scheme eligibility: buried in government portals, changes without notice.
- Forms: long, confusing, one wrong field and it bounces back.

## Solution (30s)
"Nyaya Sathi is one chat window with four expert agents behind it — an RTI drafter, a
rights navigator, a scheme eligibility reader, and a conversational form-filler. You
just describe your problem in plain language. The system figures out which specialist
you need, grounds its answer in real rules and directories, and hands you a ready-to-
file document."

## Live Demo Flow (90s)

1. **RTI Drafting** — type: *"My passport application has been stuck for 2 months, I
   want to ask why."* → show generated RTI application with correct department + fee
   note.
2. **Rights Navigator** — type: *"My landlord is not returning my security deposit."*
   → show plain-language explanation of tenant rights + concrete next steps.
3. **Scheme Eligibility** — type: *"I am a farmer with 1.5 acres, am I eligible for
   PM-KISAN?"* → show eligibility verdict + required documents.
4. **Form Filler** — show a short interview flow auto-populating a sample form field by
   field, ending in a downloadable draft.

## Why We'll Win (20s)
- All 4 illustrative directions implemented as real, callable agents — not slideware.
- Grounded in a real knowledge base, not free-form hallucination — critical for legal/
  civic trust.
- Works in mock mode with zero API cost, so it's genuinely judge-testable offline.
- Clear path to real-world scale: swap JSON for RAG over official portals, add
  regional languages, add WhatsApp channel.

## Closing Line
"We're not building another chatbot. We're building the missing translation layer
between citizens and the rights they already have."
